# Ysello follow-up update — 2026-09-06.2

## SHOP2TOPUP catalog import
- Added a full admin importer under **Admin → Supplier imports**.
- Browse SHOP2TOPUP big categories, categories/games, and purchasable subcategories/products.
- Import supplier categories into Ysello while preserving the parent/child catalog hierarchy.
- Select individual supplier products, select all filtered products, use automatic category mapping, or choose an existing Ysello category.
- Imported SHOP2TOPUP products store supplier item/category IDs, supplier USD cost, Ysello markup, fulfillment type, voucher flag, and dynamic requirement metadata.
- Imported SHOP2TOPUP products are intentionally stored as **DRAFT** until checkout collects and validates the supplier-specific player/account requirements. Admin approval is blocked while `supplierCheckoutReady` is false so a non-fulfillable top-up cannot be published by mistake.
- The importer remains visible even when the supplier account reports disabled; catalog requests will show the supplier's real error if SHOP2TOPUP itself blocks access.

## Deployment
Keep secrets in Railway; do not add them to source files.

Required server-side variables for SHOP2TOPUP:
- `SHOP2TOPUP_API_KEY`
- `SHOP2TOPUP_API_BASE_URL=https://shop2topup.com/api/endpoints/v1`
- `SHOP2TOPUP_MARGIN_PERCENT=20` (or your preferred markup)
- `SHOP2TOPUP_WEBHOOK_SECRET` after SHOP2TOPUP provides the webhook signing secret

Webhook URL:
`https://api.ysello.com/api/webhooks/shop2topup`
