# SHOP2TOPUP webhook + catalog import hotfix

- Fixed SHOP2TOPUP URL validation when a webhook secret is already configured: harmless unsigned validation probes now receive HTTP 200 instead of 401.
- Preserved HMAC-SHA256 verification for real signed order outcome callbacks.
- Raw webhook body now works regardless of validation probe Content-Type.
- Added GET and HEAD health responses and `/api/shop2topup/webhook` compatibility alias.
- Added optional `SHOP2TOPUP_WEBHOOK_PUBLIC_URL` so Admin can show a direct Railway webhook URL while a custom API hostname is not ready.
- Mapped provider errors `ACCOUNT_DISABLED`, `ACCOUNT_FROZEN`, and `IP_NOT_ALLOWED` to explicit Admin status states.
- Added "Load all games/categories" fallback so catalog browsing can work even if the top-level group list is empty but category listing is available.
