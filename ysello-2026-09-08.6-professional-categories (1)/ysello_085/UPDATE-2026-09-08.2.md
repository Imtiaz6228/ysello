# Ysello 2026-09-08.2

- Fixed the false Dark Shopping deployment mismatch. The Dark Shopping protocol version is now independent from the overall Ysello release, so newer Ysello releases remain compatible with the 2026-09-05.6 supplier contract.
- Reduced the shared marketplace feed from 500 full product records to 50 popular records and deduplicated repeated product/category requests for two minutes in the browser.
- Product detail pages now load only a small related-products query instead of downloading the full marketplace feed.
- Added short public CDN/stale-while-revalidate caching for categories and product catalog responses, plus a one-minute active category-tree cache on the API.
- Unified product artwork fallbacks so broken/missing images fall back to official platform artwork or the Ysello mark instead of leaving blank cards.
- Added category artwork fallback: uploaded category image -> official platform artwork -> clean category icon.
- Added mobile content-visibility hints for large category/product grids to reduce rendering work while scrolling.
